# Bússola

Site gratuito e open-source para aprender desenvolvimento web, com currículo estilo The Odin Project ligado a uma matriz de competências (hardskills).

- Conteúdo e interface em PT-BR.
- Desktop e mobile.
- Progresso salvo via login GitHub.
- Conteúdo versionado em `content/`, com contribuições via PR.

## Rodar localmente

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Comandos

| Comando | O que faz |
|---|---|
| `npm run dev` | servidor de desenvolvimento |
| `npm run build` | build de produção |
| `npm run lint` | ESLint |
| `npm run test` | Vitest |

Documentação: `docs/superpowers/specs/` e `docs/superpowers/plans/`.
