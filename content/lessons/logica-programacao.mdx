# Lógica de programação

Um algoritmo é uma sequência finita de passos para resolver um problema. Antes de programar, descreva a solução em linguagem natural.

## Exemplo

1. Receba dois números.
2. Some os dois.
3. Mostre o resultado.

Variáveis guardam valores. Condicionais escolhem caminhos. Laços repetem passos.
